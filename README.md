# 记一下 (EasyMoney)

> 轻量记账，支付即记账。让记一笔只需 2 次点击。

一款专为安卓设计的极简记账 App。核心理念：**支付完成 = 记账完成**，零额外操作负担。

## ✨ 核心特性

### 记账方式
- 🚀 **2 步记账** — 桌面 Widget / FAB → 输入金额 → 选分类 → 完成
- 🎤 **语音记账** — 说"午餐 38"自动填金额+分类，支持"打车 25 块 5"等多种口语
- 💬 **悬浮气泡** — 屏幕边缘小绿点，点击即刻记账，可拖动，自动吸附边缘
- 🔔 **支付自动识别** — 监听支付宝/微信/银行/云闪付通知，自动解析金额和商户，支持收入识别

### 数据管理
- 🧾 **报销管理** — 标记可报销→已报销，关联报销对象（XX公司/XX人），统计页待报销汇总
- 📂 **自定义分类** — 预设 15 个支出 + 10 个收入分类，支持增删改自定义
- ✏️ **记录编辑** — 修改金额、分类、备注、报销信息
- ⚠️ **待确认机制** — 低置信度记录标记为"待确认"，一键全部确认

### 统计与导出
- 📊 **月度环形图** — 纯 Compose Canvas 手绘，零第三方图表库
- 📈 **分类排行** — 支出/收入分类占比 + Top 6 排行
- 📤 **CSV 导出** — 一键导出账单到表格文件

### 个性化
- 🌙 **深色模式** — 跟随系统 / 浅色 / 深色三种模式
- 🎨 **Material You** — 适配 Android 12+ 动态取色
- 🖥️ **桌面 Widget** — 桌面快捷记账入口

### 隐私安全
- 🔒 **纯本地优先** — 语音识别优先离线，数据不离开设备
- 📱 **小米兼容** — HyperOS 专属权限引导，语音识别兼容方案

## 🛠 技术栈

| 类别 | 方案 |
|------|------|
| 语言 | Kotlin 1.9.22 |
| UI | Jetpack Compose + Material 3 |
| 最低版本 | Android 7 (SDK 24) |
| 目标版本 | Android 14 (SDK 34) |
| 数据库 | Room + SQLite (v4 migration) |
| 图表 | Compose Canvas（自绘） |
| 导航 | Navigation Compose |
| 架构 | MVVM（ViewModel + Repository） |
| 语音 | Android RecognizerIntent（系统语音引擎） |
| 悬浮窗 | WindowManager + ForegroundService |
| Widget | Glance AppWidget |
| 通知监听 | NotificationListenerService |
| 设置存储 | DataStore Preferences |
